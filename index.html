Perhatian: Aplikasi Sedang Dibuka dari File Lokal Laptop (file://)

Link file:///... hanya ada di laptop Anda dan tidak dapat dibuka oleh HP siswa saat di-scan. Agar dapat diakses oleh HP siswa:

  • Jalankan file ini melalui server lokal sekolah (misal XAMPP / Laragon di jaringan Wi-Fi sekolah, lalu masukkan alamat IP laptop seperti http://192.168.1.10/ujian.html), ATAU
  • Upload file HTML ini ke hosting gratis (seperti Netlify Drop, GitHub Pages, atau Vercel) lalu tempelkan URL online-nya di kolom Alamat URL Ujian di bawah ini agar QR Code otomatis valid untuk semua HP siswa!

Pastikan alamat diawali http:// atau https:// agar terbaca sebagai link aktif oleh kamera/scanner HP siswa.
